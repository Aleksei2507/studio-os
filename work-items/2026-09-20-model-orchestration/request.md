# Запрос: оркестрация моделей через инструменты хоста

## Request

Добавить в Studio OS распределение разработки между моделями: на этапе Architecture учитывать доступную ведущую модель и возможности среды, выбирать подходящих исполнителей для частей работы ради экономии токенов и качества результата.

## Expected Outcome

Студия составляет проверяемый план распределения работы, выполняет делегирование средствами хоста и проверяет полученные изменения. При отсутствии переключения моделей сохраняется полноценный процесс с одной моделью.

## Work Type

Feature

## Selected Workflow

## Product Fit

Пользователь явно подтвердил первую версию через инструменты Codex, Claude Code и других хостов с возвратом к одной модели при отсутствии переключения. Это новый Work Item после v0.6.0. Исключение multi-agent orchestration из scope прежнего v0.5 сохраняется как историческое решение; оно не изменяется задним числом.

## Known Constraints

- Делегирование выполняется только через реально доступные и разрешённые инструменты хоста.
- Не изобретать идентичность, доступность, тарифы и относительное качество моделей.
- Не обещать гарантированную экономию или совместимость со всеми LLM.
- Ведущая модель сохраняет ответственность за scope, интеграцию и качество.
- Architecture планирует распределение; выполнение начинается в Development.
- Сохранять существующие изменения пользователя и текущую работу Company Workspace.
