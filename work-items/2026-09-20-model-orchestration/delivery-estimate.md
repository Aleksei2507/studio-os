# Оценка поставки

## Scope

Один инкремент native-host оркестрации по AC1–AC8 из brief.md.

## Estimate Summary

Средний размер изменения: контракт возможностей, три Runtime, память/шаблоны, сценарии и проверка дистрибуции. Без нового сервиса или зависимостей.

## Breakdown By Iteration Or Work Item

- Контракт и Architecture: 2–4 условных часа.
- Task Decomposition и Development: 2–4 условных часа.
- Тестовые сценарии, интеграция и документация: 2–4 условных часа.

Это ориентир декомпозиции, не обещание времени LLM или календарной даты.

## Dependencies And Critical Path

Согласованный формат плана → интеграция Runtime → совместные проверки. Редактирование независимых контрактов и сценариев допускает параллельную работу.

## Validation, QA, Migration, And Release Effort

Проверки входят в инкремент; миграция только при следующем активном этапе старого проекта. Публикация релиза не запрошена.

## Operational Cost Drivers

Контекст исполнителей, повторные попытки и проверка результата. Точные тарифы и токены текущего запуска Unknown; экономия не оценена числом.

## Assumptions And Exclusions

Сохраняются существующие Markdown/JSON/Node tooling и native инструменты. Собственный API executor, платные model trials и новая UI исключены.

## Risks And Confidence

Confidence: Medium. Пересмотреть оценку при изменении scope на отдельный сервис, новой host-интеграции или провале существующих проверок.
